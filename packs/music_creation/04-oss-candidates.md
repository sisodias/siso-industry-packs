## Scoring, licences and trust

Fit: 0 irrelevant through 5 directly serves the proposed handoff. Liftability: library 5, service 4, app 3, pattern/specification 1, with actual integration cost still unmeasured. Health: archived/deprecated 0; old activity 1; intermediate/limited evidence 2; recent activity 3. No repository receives a 4–5 health claim without issue-response/support/bus-factor evidence. This conservative recency rubric does not imply that old stable libraries are defective. **Adoption is evidence coverage**, not stars: 0 means no qualifying dependency/download measurement in the inspected records; dated bank counts support the non-zero scores. Integration: 0 unrelated through 5 directly speaks the selected data objects, still requiring fixtures. No aggregate score converts missing evidence into a demonstrated product defect. [analysis]

The bank has adoption rows for Spleeter and music21 in this sample; the actual rows, dates and links are preserved in JSON. The bank README and the pinned Foundry loader disagree about whether high `fame_gap` means fame exceeds adoption or the reverse. Consequently raw downloads/dependent counts are retained **without a directional fame-gap penalty**. Missing adoption rows do not mean no users. [analysis; sources: https://github.com/sisodias/siso-repo-bank/blob/2d7d35ecbf7e1158d0a3527e1489040687ac214b/README.md ; https://github.com/sisodias/siso-foundry/blob/11f459597ce0c67dbfa89deeeafa3202e47dc6d5/pipelines/github/load_adoption_signal.py ; https://github.com/sisodias/siso-industry-packs/blob/main/registry/corrections.jsonl]

Actual retrieved licence text takes precedence over an API badge. Missing files are labelled missing, not permissive. Root pointers, dependencies, model weights, assets and alternative/commercial routes are not collapsed into one grant. Zrythm's additional licence pointer was followed; sqlite-vec has both Apache and MIT licence files, so one retrieved file does not establish a licence replacement. AudioLDM2's retrieved CC-BY-NC-SA text is noncommercial; the separate source-available flag highlights the two explicitly restricted software-product cases, not a declaration that every other row is unrestricted OSS. Exact licence readback remains authoritative. [analysis; source records per row; additional sources: https://github.com/zrythm/zrythm/blob/master/LICENSES/LicenseRef-ZrythmLicense.txt ; https://api.github.com/repos/asg017/sqlite-vec/contents?ref=main]

**ADOPT** means preferred component in a conditional design, not installed or qualified. **STUDY** retains a comparator/reference without admitting it to the base stack. **SKIP** rejects this deployment fit or evidence strength, not necessarily the project's wider value. No `STEAL` verdict is needed: copying a nonadopted implementation is not the default. Public visibility is not permission to copy restricted source; licensing is accurately recorded rather than used as a popularity score. [analysis]

## High-leverage findings

Whole-product candidates Stack Desktop and SlunderStudio are closer comparators than a generic library bundle. Project-aware backup and client-side royalty parsing also already exist, including source-available offerings. Therefore this pack rejects a blanket claim that the field is empty. Original Demucs and nussl carry explicit maintenance/deprecation warnings. CWR search produced a caching-web-radio false positive. The useful differentiated proposal is exact-revision provenance/approval linkage, not another DAW, sample browser or universal music-generation button.
