At its core is Peter Jaeckel's source code for `LetsBeRational`, an extremely fast and accurate algorithm for obtaining Black's implied volatility from option prices. Building on this solid foundation, `vollib` provides functions to calculate option prices, implied volatility and greeks using Black, Black-Scholes, and Black-Scholes-Merton. `vollib` implements both analytical and numerical greeks for each of the three pricing formulae. ## Input domain Strike prices (`K`) must be strictly positive for the Black, Black-Scholes, and Black-Scholes-Merton pricing functions. If an application wants to support `K = 0`, handle that boundary before calling `vollib`.
